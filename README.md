# Product Information System

Mini Project Pemrograman Web untuk menerapkan konsep dasar PHP dalam membangun sistem informasi produk sederhana.

## Deskripsi

Product Information System merupakan sistem yang digunakan untuk menampilkan informasi produk dan memantau kondisi persediaan.

Data produk terdiri dari ID, nama, kategori, harga, stok, dan deskripsi. Sistem juga menghitung total nilai stok serta memberikan status pada produk berdasarkan kondisi stok.

## Fitur

- Menampilkan daftar produk
- Menampilkan kategori dan harga produk
- Menghitung total stok
- Menghitung total nilai stok
- Menampilkan jumlah stok kritis
- Menampilkan status Stok Aman dan Stok Kritis
- Menampilkan ringkasan informasi produk

## Konsep Pemrograman

Project ini menerapkan:

- Konstanta menggunakan `const`
- Multidimensional array
- Function
- `require_once`
- `foreach`
- Conditional `if`
- Modular programming
